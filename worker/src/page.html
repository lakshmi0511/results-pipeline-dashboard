How to read this

Stage
Where a course is in the scoring tool: Not started → Opened → QP check → Moderation → Score summary → Awaiting verify (faculty signed off in the tool) → Verified.
Release summary
Counts across the whole pipeline, from the planner to results being published. Indented rows are subsets of the row above.
Where courses are waiting
Each row is a hand-off between two consecutive steps. A course listed there finished the first step and is waiting on the second.
Pending work queue
The single next action for every active course, oldest first. "Days" counts from the date the course became ready for that action (exam, sharing or sign-off date).
Sources
ok: read fully. partial: some pages loaded without their table, so the previous good read was kept. expired: the source showed a sign-in page; sign in again on the collector machine. failed: the read errored; the previous data is shown.
Update now / auto-update
The buttons do not read anything themselves. They set a small control record; the collector checks it every 20 seconds and reads the sources only when asked (or every 5 minutes while auto-update is on). The page reloads itself when new data arrives.
Privacy
Only course-level totals reach this page. Raw source data stays on the collector machine.
